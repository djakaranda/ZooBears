# ZooBears — проверка дат, ASR и поставки

## Даты на внутреннем dev

На 592 dev-звонках сравнивались варианты обработки с одним набором нейросетевых
кандидатов. Энкодер, словарь поиска, ruT5 для тарифов и выбор даты обучены только
на 3 334 fit-звонках из других аккаунтов. Энкодеры сравнения обучались одну эпоху
на Apple GPU. ruT5 обучался на 1 503 тарифах из fit.

| Правила дат | Precision | Recall | Temporal | State |
|---|---:|---:|---:|---:|
| Исходная сборка | 0,4091 | 0,2875 | 0,3562 | 0,1801 |
| Все изменения предыдущей итерации | 0,4003 | 0,2861 | 0,3467 | 0,1801 |
| Обновлённый парсер | 0,4091 | 0,2875 | 0,3587 | 0,1791 |
| Фильтр отказа | 0,4076 | 0,2889 | 0,3569 | 0,1812 |
| Перенос срока | 0,4091 | 0,2875 | 0,3562 | 0,1801 |
| Широкая дедупликация | 0,4059 | 0,2843 | 0,3375 | 0,1801 |
| Ранжирование дат поверх исходной сборки | 0,4091 | 0,2875 | 0,3649 | 0,1801 |

Самое заметное падение даёт широкая дедупликация. Для кандидата оставлен режим
с исходной группировкой. Для подтверждённого выезда с явно названным интервалом
сохраняются обе границы. На стабильных цепочках состояний границы остаются
согласованными. Логистическая модель ранжирует только найденные даты и время
звонка. В обучении использовано 20348 признаков.

## ASR при равном числе шагов

Каждая модель получила 3 334 fit-звонка и одни и те же 833 дополнительных
звонка, всего 98 372 реплики и 769 шагов. В контроле дополнительные звонки
содержали исходный текст. В ASR-варианте они содержали символьные подмены.
Dev использовал один синтетический шум, seed 43, rate 0,08.

| Модель и срез | Precision | Recall | Temporal | State |
|---|---:|---:|---:|---:|
| Контроль, обычный dev | 0,4091 | 0,2875 | 0,3562 | 0,1801 |
| ASR, обычный dev | 0,3421 | 0,2836 | 0,3775 | 0,1581 |
| Контроль, зашумлённый dev | 0,4578 | 0,2449 | 0,3143 | 0,1372 |
| ASR, зашумлённый dev | 0,3710 | 0,2503 | 0,3290 | 0,1298 |

Аугментация дала +0,0054 recall на шуме при −0,0868 precision и −0,0074 state.
Для внешней проверки выбраны исходные производственные веса с новым разбором дат.

## Внешний val

Одна зафиксированная конфигурация кандидата проверена на 383 звонках. В обеих
строках использованы одни и те же производственные ruBERT и ruT5 на Apple GPU.

| Конфигурация | Precision | Recall | Temporal | State |
|---|---:|---:|---:|---:|
| Исходный quality | 0,4890 | 0,4103 | 0,3963 | 0,3740 |
| Кандидат | 0,4925 | 0,4103 | 0,4042 | 0,3724 |

Temporal выше порога 0,4005 на 0,0037. Схема прошла проверку на 383 звонках, ошибок 0.
Порог по текущему состоянию составляет 0,2994 по пересчитанной базе. Кандидат
получил 0,3724.

## Поставка

Контейнерный и локальный CPU API с выбором дат совпали на 24 звонках.
Проверены закрытие прежнего состояния, явное окно выезда и отказ клиента.
Сравнение стоимости с LLM требует сопоставимых замеров учителя.
